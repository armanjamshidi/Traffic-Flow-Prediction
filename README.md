# Traffic Flow Prediction with LSTM and Temporal Attention

Cleaned research code and technical notes for:

> H. Pakparvar, S. M. Matinkhah, and A. Jamshidi, "Traffic Flow Prediction in Intelligent Transportation Systems Using LSTM With Attention Mechanism," *IEEE Access*, vol. 14, 2026, doi: [10.1109/ACCESS.2026.3686508](https://doi.org/10.1109/ACCESS.2026.3686508).

The task is one-step-ahead, single-sensor traffic-flow forecasting. A 12-sample look-back window (60 minutes at five-minute resolution) predicts the next sample.

## Repository status

This repository is a **post-publication, corrected implementation**, not a byte-for-byte archive of the code that produced the paper tables. The paper's numerical results remain the historical published results; rerunning this corrected pipeline can produce different numbers.

Important corrections and boundaries:

- Training, validation, and test periods are chronological. Overlapping sliding windows are never randomly split across training and validation.
- The scaler is fitted only on the chronological training portion.
- Windows that cross a missing timestamp interval are excluded for the ordinary LSTM models.
- TWDGCN is intentionally excluded: a single sensor provides one graph node, so no meaningful spatial graph convolution can be performed.
- GSA-KAN and DeltaRelax-LSTM are retained only as post-publication exploratory models. They are not needed to explain the paper's central LSTM-vs-LSTM+Attention comparison.
- The supplied 2024 paper split trains on February-July and tests on January. The corrected pipeline rejects that order for forward forecasting. See [the audit](docs/methodology-audit.md).
- The stored target values lie in `[0, 100]` and match the paper's described quantization step. Without the original pre-quantization scale, interpreting them as physical vehicle counts requires caution.

## Published headline results

These values are copied from the paper and are **not regenerated by this repository cleanup**.

| Dataset | Model | MAE | MSE | RMSE | MAPE | R2 |
|---|---|---:|---:|---:|---:|---:|
| 2016 | LSTM + Attention | 3.8967 | 28.6424 | 5.3519 | 18.61 | 0.9416 |
| 2016 | LSTM | 3.9239 | 29.2472 | 5.4081 | 18.47 | 0.9403 |
| 2024 | LSTM + Attention | 5.1170 | 55.0752 | 7.4213 | 17.44 | 0.9286 |
| 2024 | LSTM | 5.1183 | 55.1830 | 7.4285 | 17.01 | 0.9285 |

The 2016 improvement of attention over plain LSTM is 0.69% in MAE and 2.07% in MSE. The 2024 differences are much smaller (0.03% MAE and 0.20% MSE) and should not be overstated, especially given the reversed temporal split.

## Environment

Python 3.11-3.13 is recommended. Recreate the environment instead of copying the local `.venv` directory.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Typical commands

Train the two core models:

```bash
python train.py --model lstm
python train.py --model lstm_no_attention
```

Evaluate available models and create a comparison table:

```bash
python evaluate.py --models lstm lstm_no_attention
```

Analyze learned temporal attention:

```bash
python analyze_attention.py
```

Recreate the paper-style segmented error plots with accurate labels:

```bash
python plot_error_segments.py
```

The earlier scripts called each single-sample absolute/squared error "MAE/MSE over time." The cleaned script uses the statistically correct labels: **absolute error** and **squared error** at each sample.
