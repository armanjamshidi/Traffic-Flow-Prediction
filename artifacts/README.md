# Generated artifacts

Training and evaluation outputs are written here locally and are intentionally ignored by Git:

- `models/`: Keras models, histories, and training metadata;
- `evaluation/`: aggregate metrics and prediction overlays;
- `attention/`: attention heatmaps, entropy, clusters, and weights;
- `error_segments/`: pointwise error tables and segmented plots.

No generated artifact in this folder should be described as reproducing the paper unless it was created with the original paper code, data provenance, software versions, and evaluation protocol.
