# راهنمای آمادگی مصاحبه

این راهنما بین سه موضوع تفاوت می‌گذارد: آنچه مقاله گزارش کرده، ایرادهای نسخهٔ قدیمی، و کاری که repository اصلاح‌شده انجام می‌دهد.

## خلاصهٔ ۳۰ ثانیه‌ای

مسئله، پیش‌بینی یک‌گام جلوتر جریان ترافیک یک سنسور آزادراهی است. داده هر پنج دقیقه ثبت شده و ۱۲ مشاهدهٔ قبلی، یعنی یک ساعت گذشته، برای پیش‌بینی پنج دقیقهٔ بعد استفاده می‌شود. مدل اصلی دو لایهٔ LSTM با ۶۴ واحد دارد. در نسخهٔ attention، hidden stateهای ۱۲ گام امتیاز می‌گیرند، با softmax نرمال می‌شوند و مجموع وزن‌دار آن‌ها به لایهٔ خروجی می‌رود.

در جدول ۲۰۱۶، attention مقدار MAE را از 3.9239 به 3.8967 و MSE را از 29.2472 به 28.6424 کاهش داده است. این بهبود واقعی اما کوچک است: ۰٫۶۹٪ برای MAE و ۲٫۰۷٪ برای MSE.

## سؤال‌های مهم

### چرا LSTM؟

داده سری زمانی و غیرخطی است. gateهای input، forget و output به LSTM اجازه می‌دهند اطلاعات مرتبط را در توالی نگه دارد. چون فقط یک سنسور داریم، وابستگی اصلی زمانی است، نه مکانی.

### attention دقیقاً چه می‌کند؟

برای هر hidden state زمانی یک امتیاز scalar محاسبه می‌شود. softmax این امتیازها را به وزن‌هایی تبدیل می‌کند که مجموعشان یک است. context vector مجموع وزن‌دار hidden stateهاست. این وزن‌ها تمرکز داخلی مدل را نشان می‌دهند، اما تفسیر علّی ندارند.

### نشت زمانی validation چه بود؟

نسخهٔ قدیمی ابتدا پنجره‌های هم‌پوشان می‌ساخت و سپس آن‌ها را shuffle و تقسیم می‌کرد. دو پنجرهٔ مجاور از ۱۲ ورودی، ۱۱ مقدار مشترک دارند. حتی target یک نمونهٔ validation می‌تواند داخل ورودی نمونهٔ زمانی بعدی train باشد. نسخهٔ فعلی ابتدا ردیف‌ها را زمانی جدا می‌کند و بعد در هر بخش مستقل window می‌سازد.

### آیا cross-validation استفاده شد؟

خیر. روش مقاله یک holdout بود، نه K-fold و نه walk-forward. نسخهٔ اصلاح‌شده holdout زمانی مستقل دارد. walk-forward می‌تواند کار آینده باشد، اما نتایج چاپ‌شده بر مبنای آن نیست.

### چرا TWDGCN حذف شد؟

GCN برای message passing به چند node و adjacency واقعی نیاز دارد. داده فقط یک سنسور/node دارد؛ بنابراین نسخهٔ قدیمی رابطهٔ مکانی معناداری یاد نمی‌گرفت و نام GCN برای آن قابل دفاع نبود.

### مشکل split سال ۲۰۲۴ چیست؟

train از فوریه تا ژوئیهٔ ۲۰۲۴ است، ولی test ژانویهٔ ۲۰۲۴ است. پس test قبل از train قرار دارد. این یک آزمون retrospective است، نه پیش‌بینی آینده. pipeline فعلی این ترتیب را رد می‌کند.

### چرا نتایج جدید با مقاله فرق می‌کنند؟

validation زمانی اصلاح شده، windowهای عبورکننده از gap حذف شده‌اند، scaler فقط روی train fit می‌شود، برخی مدل‌های جانبی تغییر کرده‌اند و نسخهٔ کتابخانه‌ها نیز ممکن است متفاوت باشد. بنابراین نتایج جدید نباید با جدول تاریخی مقاله یکی فرض شوند.

### مشکل مقیاس داده چیست؟

مقاله توضیح می‌دهد داده به `[0,1]` نرمال، در ۱۰۰ ضرب و integer شده و دوباره برای مدل scale شده است. CSVهای موجود هم در بازهٔ ۰ تا ۱۰۰ هستند. بدون min/max اولیه نمی‌توان با قطعیت گفت خطاها در واحد خام خودرو هستند.

### چرا MAPE معیار اصلی مناسبی نیست؟

جریان می‌تواند صفر یا نزدیک صفر باشد و MAPE در این نقاط ناپایدار است. حذف صفرها نیز تعریف معیار را عوض می‌کند. نسخهٔ فعلی MAE، RMSE، R2، SMAPE و WAPE را گزارش می‌کند.

### وضعیت GSA-KAN و DeltaRelax-LSTM چیست؟

آن‌ها baselineهای اکتشافی‌اند. نسخهٔ قدیمی GSA-KAN، spline KAN واقعی نبود و DeltaRelax نیز delta-time واقعی دریافت نمی‌کرد. نسخهٔ فعلی این موارد را اصلاح کرده، اما این اصلاحات پس از انتشارند و نتایجشان نباید به جدول قدیمی نسبت داده شود.

## معماری و shapeها

```text
CSV rows
  -> chronological split
  -> train-only MinMaxScaler
  -> X: (samples, 12, 1)
  -> LSTM(64, return_sequences=True)
  -> Batch Normalization
  -> LSTM(64, return_sequences=True)
  -> temporal attention over 12 steps
  -> context vector (64)
  -> dropout
  -> Dense(1, sigmoid)
```

baseline بدون attention از hidden state نهایی LSTM دوم استفاده می‌کند.

## اعداد مهم

- sampling interval: پنج دقیقه
- look-back: دوازده گام یا ۶۰ دقیقه
- forecast horizon: یک گام یا پنج دقیقه
- دو LSTM با ۶۴ واحد
- batch size مقاله: ۲۵۶
- حداکثر epoch: ۶۰۰
- dropout مقاله: ۰٫۱
- دادهٔ ۲۰۱۶: ۷۷۷۶ ردیف train و ۴۳۲۰ ردیف test
- دادهٔ ۲۰۲۴ workdays: ۳۶۱۸۷ ردیف train و ۶۶۱۸ ردیف test

## محدودیت‌هایی که باید صادقانه بیان شوند

- فقط یک سنسور و یک feature اصلی وجود دارد.
- weather، incident، road work و eventها وارد مدل نشده‌اند.
- horizon فقط پنج دقیقه است.
- context یک‌ساعته الگوی روزانه و هفتگی را مستقیم پوشش نمی‌دهد.
- split سال ۲۰۲۴ رو به عقب است.
- اثر attention کوچک است و معنی‌داری آماری با چند seed گزارش نشده است.
- attention weight معادل causal explanation نیست.
- provenance و مقیاس خام داده کامل ثبت نشده است.
